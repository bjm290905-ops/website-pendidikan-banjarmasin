Paket website Pendidikan Banjarmasin

Isi ZIP:
- index.html
- styles.css
- app.js (perbaikan pembacaan data dan cache)
- school-data.js (1.087 satuan pendidikan, 21 bentuk)

Cara pakai:
1. Ekstrak semua isi ZIP.
2. Unggah ke root repository GitHub website-pendidikan-banjarmasin.
3. Ganti file bernama sama jika diminta.
4. Commit perubahan dan tunggu GitHub Pages selesai deploy.
